RUTHLESS WEBSITE


FILES

index.html          Animated Ruthless intro screen. Automatically opens the main site.
ruthlessweb2.html   Main Ruthless guild website.
nickname.html       Ruthless nickname generator.
styles.css          Shared responsive styling for all pages.
main.js             Main site navigation, scroll reveals and footer year.
generator.js        Nickname generation, validation, copy and reset logic.
assets/             Your two supplied transparent character PNG images.

HOW TO RUN

1. Extract the ZIP file.
2. Keep the folder structure exactly as it is.
3. Open index.html in a browser. You can also open ruthlessweb2.html directly.
4. The nickname generator is linked from the homepage.

IMPORTANT

The WhatsApp tryout group link and three contact numbers were retained from the
original code. Verify that they are still correct before publishing.
The original guild history and recruitment requirements were retained. No
unprovided tournament wins, player statistics or achievements were invented.

PUBLISHING

You can host this static website on GitHub Pages, Netlify or another static
website host. Upload the extracted project with the folder structure intact.
